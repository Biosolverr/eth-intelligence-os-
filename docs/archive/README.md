[`../TESTING_GUIDE.md`](../TESTING_GUIDE.md) and [`../TEST_RESULTS.md`](../TEST_RESULTS.md).

|---|---|

| `STUDIO_RUNBOOK.md`, `STUDIO_RUNBOOK_READY.md`, `STUDIO_RUNBOOK_FINAL.md` | earlier English runbook drafts (parts A-D and the "final run" draft) |
| `STUDIO_RUNBOOK_RU.md` | Russian block-by-block runbook (blocks 1-11) used for the final run; the addresses written inside belong to an earlier deployment, the final ones are in `../TEST_RESULTS.md` |
| `gltest_failures/` | raw failure dumps of two early gltest runs (G3 analyze, G8 resolve with the blocked price host); the causes were fixed, see `../TEST_REGISTER.md` |
| `REHEARSAL_DEPLOYMENTS.md` | note on the rehearsal deployments that preceded the final one |
